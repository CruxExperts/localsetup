# LocalSetup 4.22.9

This maintenance release fixes OpenCode inventory limits and makes unavailable workflow selections actionable during recorded updates.

## Highlights

- **Reliable OpenCode inventory:** Ordinary package references no longer consume the directory traversal budget. Resolved directories are scanned once, with separate directory and total-entry limits. Recursive scanning still detects nested skill-name conflicts; malformed metadata, cycles, and unresolved links still block unsafe updates.
- **Actionable update reports:** Healthy recorded personal, combined, and retained-repository updates identify every missing selection. Reports name owning skills for eight consolidated workflows and distinguish unknown selections or absent replacements. Recorded selections and ownership state are preserved for review.

See the [published release and downloads](https://github.com/CruxExperts/localsetup/releases/tag/v4.22.9) for release assets.

## Compatibility

Existing repair blockers still take precedence. This release does not change dependency versions or native runtime behavior.

Custom skills, ordinary files, and project-owned symlinks in adapter directories remain project-owned. Unavailable selections are reported rather than automatically migrated.

The adapter ownership guide documents recorded-update reports and the workflow retirement mapping. The earlier 4.4.0 guide remains release history.

## Update

Follow the quickstart update instructions to refresh the registered source to the intended release. `localsetup update` reapplies that source; it does not download a newer framework release. Explicit source checkouts remain under the user's control.

Once the registered source is current, preview the target:

```bash
localsetup plan --target-directory .
```

Review selections and clear blockers before applying:

```bash
localsetup update --target-directory .
localsetup verify --level filesystem
```

For installation and source refresh, read the [quickstart update instructions](../QUICKSTART.md#update). Adapter changes follow the [adapter ownership guide](../ADAPTER_OWNERSHIP.md).

## Verify the download

Download `localsetup-v4.22.9.tar.gz`, `localsetup-v4.22.9.tar.gz.sha256`, and `localsetup-v4.22.9.tar.gz.cdx.json` from the published 4.22.9 release and keep all three files in the same directory.

The published release also includes a Python wheel and source distribution, and the unchanged native sandbox bundle with its provenance, SBOM, and corresponding sources from 4.22.7. Native artifacts are byte-identical to that release.

Download the framework archive with both its `.sha256` checksum and `.cdx.json` SBOM sidecars. Keep all three files in the same directory before running `verify-release`.

```bash
uv run --locked python ls/tools/localsetup.py --source-root . verify-release /path/to/localsetup-v4.22.9.tar.gz
```
