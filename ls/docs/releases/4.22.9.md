# LocalSetup 4.22.9

This maintenance release fixes OpenCode inventory limits and makes unavailable workflow selections actionable during recorded updates. See the [published release](https://github.com/CruxExperts/localsetup/releases/tag/v4.22.9) for downloads and the complete release notes.

## What changed

- **OpenCode inventory ([#93](https://github.com/CruxExperts/localsetup/issues/93)):** Ordinary package references no longer consume the directory traversal budget. Resolved directories are scanned once, with separate directory and total-entry limits. Recursive scanning still detects nested skill-name conflicts; malformed metadata, cycles, and unresolved links still block unsafe updates.
- **Unavailable workflow selections ([#94](https://github.com/CruxExperts/localsetup/issues/94)):** Healthy recorded personal, combined, and retained-repository updates identify every missing selection. Reports name owning skills for eight consolidated workflows and distinguish unknown selections or absent replacements. Recorded selections and ownership state are preserved; users review the report before changing their selection.

The [adapter ownership guide](../ADAPTER_OWNERSHIP.md) documents recorded-update reports and the workflow retirement mapping. Existing repair blockers still take precedence. This release does not change dependency versions or native runtime behavior.

## Updating

Follow the [quickstart update instructions](../QUICKSTART.md#update) to refresh the registered source to the intended release. `localsetup update` reapplies that source; it does not download a newer framework release. Explicit source checkouts remain under the user's control.

Once the registered source is current, preview the target project:

```bash
localsetup plan --target-directory .
```

Review the reported selections and clear blockers before applying:

```bash
localsetup update --target-directory .
localsetup verify --level filesystem
```

Custom skills, ordinary files, and project-owned symlinks in adapter directories remain project-owned. Unavailable selections are reported rather than automatically migrated.

## Downloads and verification

The published release includes the framework archive and SBOM, Python wheel and source distribution, and the unchanged native sandbox bundle with its provenance, SBOM, and corresponding sources from 4.22.7. Native artifacts are byte-identical to that release.

Download `localsetup-v4.22.9.tar.gz`, `localsetup-v4.22.9.tar.gz.sha256`, and `localsetup-v4.22.9.tar.gz.cdx.json` from the [4.22.9 assets](https://github.com/CruxExperts/localsetup/releases/tag/v4.22.9). Keep all three files in the same directory. From a source checkout, verify the downloaded archive:

```bash
uv run --locked python ls/tools/localsetup.py --source-root . verify-release /path/to/localsetup-v4.22.9.tar.gz
```

The [versioning guide](../VERSIONING.md) explains release checks. The [4.4.0 guide](4.4.0.md) preserves the earlier context and package consolidation history.
